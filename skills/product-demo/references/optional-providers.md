# Optional capabilities and the evaluated alternatives

Use local capture plus Remotion/Snapcn for accurate product footage, change reviews, diagrams and presentations. It does not need a video-generation account. External models can produce illustrative footage or atmosphere, but should not synthesize the UI or evidence that a bug was fixed.

The evaluated [101-skills AI video generation skill](https://github.com/101-skills/superpowers/tree/main/tools/video/ai-video-generation) routes to inference.sh through its `belt` CLI. It is useful for generated B-roll, image-to-video and avatar/lipsync work. It introduces an account, provider pricing and model-dependent results. If that capability is needed, read the current official setup and model schema, confirm existing credentials and cost authority, generate only the needed clip, then stage it as media in this composition. Do not install a large provider catalogue merely to create an ordinary software demo.

[HyperFrames general-video](https://github.com/heygen-com/hyperframes/tree/main/skills/general-video) provides an HTML/timeline alternative with extensive design, audio, media and review workflows. It depends on companion skills and its runtime; `general-video` alone is not a complete standalone install. Use it for an existing HyperFrames project or an explicitly selected HTML workflow. Preserve its supported timeline/check/render contract rather than importing fragments of its internal scripts into Remotion. Its useful production ideas here are a coherent brief, staged assets, deterministic time, scene checks and final artifact inspection.

For either service, verify current pricing, available models and licence terms before dispatch. Respect the host's budgets and authorizations, retain uncertain charges, and stop repeated failures. Do not create credentials, enroll in a paid plan or upload private captures without the relevant authority. These are optional paths; their absence should not block a local video that needs neither.
